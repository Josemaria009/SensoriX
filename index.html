Guía Paso a Paso: Vinculación de Notificaciones de Telegram

Sigue minuciosamente cada uno de los 3 pasos descritos a continuación para habilitar y recibir alertas críticas directamente en tu celular o canal grupal.

1
Creación e Inicialización del Bot en Telegram
Abre la aplicación de Telegram en tu dispositivo móvil o computadora. En la barra de búsqueda global, localiza el usuario verificado de gestión oficial: @BotFather. Inicia la interacción enviando el comando exacto /newbot. El sistema te solicitará ingresar un nombre visible y posteriormente un usuario único finalizado obligatoriamente en "bot" (ejemplo: mi_sensorix_bot). Al finalizar el proceso, BotFather te desplegará un mensaje con tu HTTP API Token (una cadena similar a 123456789:ABCdefGhIJKlmNoPQ...). Copia esta clave de acceso de inmediato.
2
Almacenamiento del Token y Permisos del Chat
Pega el Token que acabas de copiar dentro del campo "Token Global del Bot de Telegram" ubicado en el panel inferior de esta sección y presiona el botón Guardar Token.
¡ACCIÓN REQUERIDA OBLIGATORIA! Telegram restringe los mensajes automatizados si no existe una autorización previa por privacidad. Debes ingresar al chat personal de tu bot recién creado y presionar el botón Iniciar / Start (o enviar cualquier mensaje escrito) para habilitarle el permiso de envío de notificaciones directas.
3
Identificación y Asignación del Chat ID a cada SITE
Una vez iniciado el chat con tu bot, haz clic en el botón Detectar Chats Disponibles que se muestra en la tarjeta inferior. La plataforma consultará la API de Telegram y desplegará en pantalla tu nombre de usuario junto a tu identificador único numérico (Chat ID).
Apunta este número e ingrésalo en el módulo Configuración de límites del SITE que desees monitorear. Esto vinculará las alertas meteorológicas y térmicas de esa ubicación específica con tu cuenta.

Conexión con Wokwi: Sensor ESP32 + DHT22

Un ESP32 simulado en Wokwi mide temperatura, humedad y fuga de agua, y las envía a un puente de Google Apps Script. SensoriX consulta ese puente cada 5 segundos y registra las lecturas como SENSOR REAL, con sus alertas y notificaciones de Telegram.

ESP32 + DHT22Wokwi (simulador)
Google Apps ScriptPuente HTTP
SensoriXDashboard y alertas
1
Crear el proyecto en Wokwi
Entra a wokwi.com → New Project → ESP32 (Arduino). Pega Wokwi_ESP32_DHT22.ino en sketch.ino, diagram.json en su pestaña y libraries.txt en la suya. El circuito lleva el DHT22 en el pin D15 y un slider en D34 que simula un sensor de agua analógico (nivel de 0 a 100 %).
2
Publicar el puente en Google Apps Script
En script.google.com crea un proyecto nuevo y pega Apps_Script_SensoriX.gs. Cambia API_KEY por una clave tuya. Ve a Implementar → Nueva implementación → Aplicación web con Ejecutar como: Yo y Acceso: Cualquier persona, autoriza los permisos y copia la URL que termina en /exec. Compruébala abriéndola en una ventana de incógnito con ?action=read&key=TU_CLAVE al final: debe mostrar un JSON y no pedir inicio de sesión.
3
Configurar el ESP32 y encender la simulación
En sketch.ino reemplaza SCRIPT_URL, API_KEY y SITE_NOMBRE (el nombre del SITE tal como está en SensoriX, no el número de segmento) y pulsa Play. En el monitor serial debes ver HTTP 200 → {"ok":true} cada 10 segundos.
4
Vincular el puente con SensoriX
Pega la URL /exec y la misma clave en el formulario de abajo y pulsa Guardar y conectar. Cada lectura se asigna al SITE cuyo nombre coincida con SITE_NOMBRE (no distingue mayúsculas ni acentos). Cuando el estado cambie a RECIBIENDO DATOS, abre Detalle de SITE y verás la etiqueta SENSOR REAL.
5
Provocar alertas desde Wokwi
Haz clic en el DHT22 dentro de Wokwi y sube la temperatura o la humedad por encima de los límites del SITE. Sube el slider del sensor de agua por encima del 35 % para simular una inundación (se envía al instante) y bájalo por debajo del 25 % para volver a seco. La alerta aparecerá en el Historial de Alertas y en Telegram si lo vinculaste.
6
Vincular Telegram al SITE de Wokwi
En la tarjeta Notificaciones de Telegram de abajo elige el SITE (el mismo cuyo nombre pusiste en SITE_NOMBRE), pega su Chat ID, pulsa Guardar Chat ID y luego Enviar prueba. También necesitas el Bot Token guardado en la sección Notificaciones Telegram. Cada alerta se envía una vez (no se repite en 5 minutos) y recibes un aviso de SIN SEÑAL si el ESP32 deja de enviar datos y de SEÑAL RESTABLECIDA cuando vuelve.

¿Dónde y cómo obtener tu Chat ID de Telegram?

1
Abre Telegram en tu teléfono o computadora y busca el usuario verificado @BotFather.
2
Escríbele /newbot, asigna un nombre y te entregará tu Bot Token. Almacénalo en el apartado "Notificaciones Telegram".
3
Inicia conversación directa con tu Bot enviando cualquier mensaje y luego presiona "Detectar Chats Disponibles" para obtener tu Chat ID numérico.
Puedes vincular un Chat ID diferente para cada SITE en el menú Configuración de límites.
