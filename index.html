Guía Paso a Paso: Vinculación de Notificaciones de Telegram

Sigue minuciosamente cada uno de los 3 pasos descritos a continuación para habilitar y recibir alertas críticas directamente en tu celular o canal grupal.

1
Creación e Inicialización del Bot en Telegram
Abre la aplicación de Telegram en tu dispositivo móvil o computadora. En la barra de búsqueda global, localiza el usuario verificado de gestión oficial: @BotFather. Inicia la interacción enviando el comando exacto /newbot. El sistema te solicitará ingresar un nombre visible y posteriormente un usuario único finalizado obligatoriamente en "bot" (ejemplo: mi_sensorix_bot). Al finalizar el proceso, BotFather te desplegará un mensaje con tu HTTP API Token (una cadena similar a 123456789:ABCdefGhIJKlmNoPQ...). Copia esta clave de acceso de inmediato.
2
Almacenamiento del Token y Permisos del Chat
Pega el Token que acabas de copiar dentro del campo "Token Global del Bot de Telegram" ubicado en el panel inferior de esta sección y presiona el botón Guardar Token.
¡ACCIÓN REQUERIDA OBLIGATORIA! Telegram restringe los mensajes automatizados si no existe una autorización previa por privacidad. Debes ingresar al chat personal de tu bot recién creado y presionar el botón Iniciar / Start (o enviar cualquier mensaje escrito) para habilitarle el permiso de envío de notificaciones directas.
3
Identificación y Asignación del Chat ID a cada SITE
Una vez iniciado el chat con tu bot, haz clic en el botón Detectar Chats Disponibles que se muestra en la tarjeta inferior. La plataforma consultará la API de Telegram y desplegará en pantalla tu nombre de usuario junto a tu identificador único numérico (Chat ID).
Apunta este número e ingrésalo en el módulo Configuración de límites del SITE que desees monitorear. Esto vinculará las alertas meteorológicas y térmicas de esa ubicación específica con tu cuenta.

¿Dónde y cómo obtener tu Chat ID de Telegram?

1
Abre Telegram en tu teléfono o computadora y busca el usuario verificado @BotFather.
2
Escríbele /newbot, asigna un nombre y te entregará tu Bot Token. Almacénalo en el apartado "Notificaciones Telegram".
3
Inicia conversación directa con tu Bot enviando cualquier mensaje y luego presiona "Detectar Chats Disponibles" para obtener tu Chat ID numérico.
Puedes vincular un Chat ID diferente para cada SITE en el menú Configuración de límites.
