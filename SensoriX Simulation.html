Guía Fácil para Conectar tu Chatbot de Alertas

Sigue estos 3 sencillos pasos para recibir alertas instantáneas directamente en tu celular o grupo de trabajo.

1
Crea tu Bot en Telegram
Abre Telegram en tu celular o PC, busca el usuario oficial @BotFather y envíale el comando /newbot. Elige un nombre para tu bot y copia la clave token que te entregará (ejemplo: 123456789:ABCdef...).
2
Guarda el Token y Activa el Bot
Pega la clave token en el campo de abajo y presiona Guardar Token.
¡Paso muy importante! Entra a tu nuevo Bot en Telegram y presiona Iniciar / Start (o envíale cualquier mensaje) para autorizarlo a escribirte.
3
Vincula tu Chat ID a cada SITE
Presiona el botón Detectar Chats Disponibles de abajo. La aplicación identificará tu usuario. Copia el Chat ID que aparezca y asígnalo en la pestaña Configuración Límites del SITE que desees.

¿Dónde y cómo obtener tu Chat ID de Telegram?

1
Abre Telegram en tu teléfono o computadora y busca el usuario oficial @BotFather.
2
Escríbele /newbot, asigna un nombre y te entregará tu Bot Token. Guarda el Token en la pestaña "Notificaciones Telegram".
3
Inicia conversación con tu Bot, envía cualquier mensaje y luego usa la herramienta "Detectar Chats Disponibles" para copiar tu Chat ID único.
Puedes vincular un Chat ID diferente para cada SITE en el menú Configuración Límites.
